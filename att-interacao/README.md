# Gerenciador de Tarefas (React + Vite)

Projeto criado para a atividade prática de CRUD
- API utilizada: JSONPlaceholder (https://jsonplaceholder.typicode.com)
- Ferramenta: Vite + React

## Como usar
1. Instale dependências: `npm install`
2. Rode em desenvolvimento: `npm run dev`
3. o endpoint :`http://localhost:5173/`

## O que foi implementado
- CRUD completo (listar, criar, atualizar, deletar) usando `fetch`.
- Tratamento de erros .

## Observações
- JSONPlaceholder é uma API publica então não salva (POST/PUT/DELETE eles retornam respostas,mas não fica salvo).
